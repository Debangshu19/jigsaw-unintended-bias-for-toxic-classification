STAGE 2 · DISTILBERT TRANSFORMER

Stage 2 — DistilBERT: a fine-tuned transformer

The RNN models in Stage 1 read a sentence one word at a time and kept a single fixed vector per word. That gave two problems: long-range context decays as it passes through the chain, and a word like "killed" gets the same vector whether it is a threat or a sports headline. A transformer fixes both. We did not train one from scratch — we took an existing pretrained model and fine-tuned it.

Why attention beats recurrence

The transformer (Vaswani et al., 2017 literature) replaces recurrence with self-attention. Three properties matter here:

  • Short path length. Self-attention connects every pair of tokens directly, so the path between any two words is O(1), against O(n) for an RNN that must pass information step by step. Long-range context is reached in one hop. literature
  • Contextual, bidirectional embeddings. Each token's vector is computed from the whole sentence, so the same word gets a different representation in a different context. This is what removes the fixed-vector limit behind the "killed it" problem. literature
  • Parallel and pretrained. All positions are processed in parallel (no sequential dependency), and the backbone is pretrained on a large corpus. Fine-tuning then needs only a little task data — this is transfer learning. literature
RNN inter-token path = O(n) → signal decays over distance
self-attention inter-token path = O(1) → direct long-range link

What we actually did

We did not distill anything ourselves. We took the already-distilled distilbert-base-uncased and fine-tuned it. DistilBERT (Sanh et al., 2019 literature) is the result of distilling BERT-base into a smaller student: about 66M parameters, 6 transformer layers, roughly 40% smaller and 60% faster than BERT while keeping about 97% of its performance literature. We fine-tuned it on a balanced 100k subset of Jigsaw (50k toxic + 50k non-toxic, split 80k train / 20k val) measured by us.

The architecture, layer by layer: WordPiece tokenizer (vocab 30,522, max length 128) → embeddings → 6 transformer blocks (each with 12 attention heads and a feed-forward block 768→3072→768) → the first-token [CLS] hidden state (768-d) → pre_classifier Linear(768→768) with ReLU and dropout → classifier Linear(768→2) → softmax giving P(toxic). Training used the HuggingFace Trainer with AdamW, learning rate about 5e-5, batch size 16, on a single GPU.

Takeaway. The win over the RNN family is in behaviour, not raw accuracy. DistilBERT reaches about 0.90 toxic recall on the balanced 20k val set measured by us, while the simple high-accuracy baseline TF-IDF + Logistic Regression had toxic recall below 0.45 on the large imbalanced split measured by us — it missed more than half of all toxic comments. Both DistilBERT runs (1 epoch and 3 epochs) are Regime B (balanced 20k val); the TF-IDF + Logistic Regression recall above is Regime A (the large imbalanced split). Recall on a balanced set and recall on a heavily imbalanced set are different regimes, so this is not a like-for-like number — treat the DistilBERT-vs-RNN-family comparison as a qualitative illustration of the imbalance-failure point, not a direct metric.

The drawback that remains

Honest caveat. Four limits stay with this model. (1) It is a compressed model — 66M params, 6 layers — so it has a capacity ceiling. (2) Mild overfitting at 3 epochs: training to 3 epochs lowered training loss (0.6075 → 0.4207) but raised validation loss (0.537 → 0.818) with no accuracy gain, so about 1 epoch was near-optimal for this 100k subset. (3) It is a single model — its errors have an irreducible variance that one model cannot average away. (4) Scope limits: English, uncased, a 128-token cap, and trained only on the balanced subset.

This points to two ways forward. Raise the capacity ceiling by scaling the model up (Stage 3), and reduce single-model variance by combining several models (Stage 4).

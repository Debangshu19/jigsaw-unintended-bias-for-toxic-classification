FOUNDATIONS · DATA & METRICS

Data and how we measure

The English track uses the Jigsaw "Unintended Bias in Toxicity Classification" data (the Civil Comments corpus). It has 1,804,871 comments measured by us. Each comment carries a continuous target in [0,1]. We treat a comment as toxic when target ≥ 0.5, so the score is binarised at 0.5. The data also has identity columns (muslim, black, white, female, and others) that let us measure bias by group.

Why balancing and the right metric matter

The raw data is heavily imbalanced: 1,660,537 non-toxic against 144,334 toxic comments measured by us. That is about 11.5 : 1, roughly 8% toxic. On data like this, plain accuracy is misleading. A model that labels everything "non-toxic" already scores about 92% accuracy while catching no toxic comment at all. So we cannot trust accuracy alone; we have to look at how the minority (toxic) class is handled.

The metrics, one line each

MetricPlain definition
AccuracyFraction of all comments labelled correctly.
Precision (toxic)Of the comments we flagged toxic, how many really were.
Recall (toxic)Of the truly toxic comments, how many we caught.
F1 (toxic)Harmonic mean of precision and recall — one number that balances both.
Macro-F1F1 computed per class, then averaged — treats both classes equally regardless of size.
ROC-AUCProbability the model ranks a random toxic comment above a random non-toxic one.
Jigsaw bias-aware AUCA weighted blend of the overall AUC and per-identity-subgroup AUCs, so a model is rewarded only if it ranks well within each identity group, not just on average.

Two evaluation regimes — kept separate on purpose

The numbers in this project come from two different setups. We keep them apart because mixing them would be a mistake.

Regime A — RNN / classical family

  • Trained and evaluated on the large, imbalanced split.
  • Reported with the Jigsaw bias-aware AUC.
  • Keras tokenizer, vocab 100,000, max_sequence_length 300.
  • Pretrained 300-d word embeddings, shape (276,289 × 300).

Regime B — DistilBERT

  • Trained on a balanced down-sample: 50,000 per class = 100,000.
  • Split 80/20 → 80,000 train / 20,000 val (10k per class).
  • Reported with plain accuracy / F1 / ROC-AUC on that balanced val set.
  • WordPiece tokenizer, 30,522 vocab, max_length 128.
Honest caveat. The RNN/classical numbers (Regime A) and the DistilBERT numbers (Regime B) were measured under different data splits, sequence lengths, and metrics — one uses bias-aware AUC on the large imbalanced set, the other uses plain ROC-AUC on a balanced 20k val set. So their headline numbers are not directly comparable. We do not put them side by side and pick a winner on raw accuracy. Instead we compare behaviour, especially recall on the toxic class.

Takeaway. For moderation, recall on the toxic (minority) class is the number that actually matters. A missed toxic comment (false negative) is the costly error — it reaches users. High accuracy on an 11.5:1 split can hide a model that misses most toxic comments, so we judge models by how much of the toxic class they catch.

THE FINAL ENGLISH MODEL · CAPABILITIES & LIMITS

The final model — what it does and where it stops

This is the saved English model: a fine-tuned DistilBERT classifier, served end to end. It is one model behind one API, used by three clients. Below is an honest split of what it can do and what it cannot.

What it can do

Contextual transformer

Six transformer blocks read the whole sentence at once, so the same word is read differently depending on its context — unlike the fixed word vectors used by the RNNs.

Measured accuracy

On the balanced 20k validation set: accuracy 0.8851, F1 (toxic) 0.887, ROC-AUC 0.9515. measured by us

Catches most toxic comments

Toxic recall 0.899 — it misses about one in ten toxic comments, far better than the simple high-accuracy models that miss over half. measured by us

Served end to end

A FastAPI service runs the model, with a fallback chain (real model → LLM via gateway → keyword heuristic) so a live demo never hard-crashes.

One contract, three clients

A React website, a Chrome extension (X / YouTube / Instagram), and an Expo mobile shell all speak the same API contract.

Explanations + a tunable threshold

Per-category scores and word-level explanations (occlusion), plus a decision threshold a moderator can move to trade precision against recall.

Where it stops

  • English-only and uncased. The tokenizer lowercases input, so it loses signal from SHOUTING in all caps. measured by us
  • Short inputs only. Hard cap of 128 tokens; longer comments are truncated. measured by us
  • Trained on a subset, not the full corpus. A balanced down-sample of 100,000 comments (50k per class), not all 1,804,871. measured by us
  • Binary head only. It outputs toxic / non-toxic; it does not name the toxicity type from this head.
  • Mild overfitting past one epoch. Three epochs lowered training loss but raised validation loss (0.537 → 0.818) with no accuracy gain, so ~1 epoch was near-optimal for this subset. measured by us
  • Identity bias not yet mitigated. The dataset's identity columns make bias measurable, but we have not measured or corrected it here.
  • It is a single model. One model carries single-model variance and correlated errors — exactly what the averaging step (Stage 4) is meant to cut. proposed next step
Takeaway. A solid, honest single classifier — 0.8851 accuracy, 0.887 F1, 0.9515 ROC-AUC, ~0.90 toxic recall — that works end to end across three clients. Its main open weaknesses are English-only / uncased input, unmitigated identity bias, and being a single model.
Honest caveat. These numbers are for the English DistilBERT track only. They are not a baseline for the Hindi RAVEN-X work, which is a different language, task, and label scheme.

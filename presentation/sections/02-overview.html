What this project is

Raven is a system that detects toxic and hate-speech comments. It answers one question: which comments need a human moderator to look at? Instead of a person reading every comment, Raven flags the risky ones as "needs review" and lets the safe ones through. The point is to save the moderator's time, not to replace their judgement.

What we built

One model, one API, and three clients. The three clients all speak the same API contract.

The model

A fine-tuned DistilBERT classifier that outputs P(toxic) for a comment. measured by us

The API

A FastAPI service (raven-api). It has a fallback chain (real model → LLM via gateway → keyword heuristic) so a demo never hard-crashes.

Web client

A React website (raven-web) with a live demo you can type into.

Browser extension

A Chrome Manifest-V3 extension (extension) that flags comments inline on X, YouTube and Instagram.

Mobile client

An Expo mobile shell (raven-mobile) that calls the same API.

The dataset (English track)

We trained the English model on the Jigsaw "Unintended Bias in Toxicity Classification" corpus (Civil Comments).

PropertyValue
Total comments1,804,871 measured by us
Class balance1,660,537 non-toxic vs 144,334 toxic (~11.5 : 1, about 8% toxic)
Labelcontinuous target in [0,1], binarised at 0.5 (target ≥ 0.5 → toxic)
Bias measurementidentity columns (muslim, black, white, female, …) allow per-subgroup checks
Honest caveat. Two model families in this document were measured under two different evaluation regimes, and we keep them separate. The RNN/classical family was evaluated on the large split with the Jigsaw bias-aware AUC. DistilBERT was evaluated on a balanced 100,000-comment down-sample (50,000 per class) with plain accuracy/F1/ROC-AUC. The two sets of numbers are not directly comparable.

Roadmap — how this document reads

The talk walks up a ladder of model capacity, and then turns to our own contribution.

  1. Classical / TF-IDF — bag-of-words with logistic regression, the simplest baseline.
  2. LSTM & RNN family — single LSTM, BiLSTM, weighted BiLSTM, BiGRU with attention.
  3. DistilBERT — our transformer: a distilled backbone we fine-tuned.
  4. Larger transformer — the next capacity step (reasoning + literature, proposed next step, not run by us).
  5. Ensemble — simple averaging of diverse models (theory + Kaggle literature).
  6. Final model — what it can and cannot do, stated honestly.
  7. RAVEN-X — our original contribution: cross-script rationale transfer for low-resource Hindi.
  8. Architecture diagrams — how the pieces fit together.
Takeaway. Raven is a toxicity triage system: one fine-tuned model behind one API, used by three clients. This document climbs from a simple baseline up to a transformer and an ensemble, then presents RAVEN-X, our own method for low-resource Hindi.

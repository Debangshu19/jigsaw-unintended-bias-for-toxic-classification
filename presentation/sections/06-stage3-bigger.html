STAGE 3 · A BIGGER TRANSFORMER

Stage 3 — Scaling up to a larger transformer

The next idea was to ask: what if we made the model bigger? In an early discussion this was phrased as moving to a "DistilBERT large". We want to be honest about two things up front.

Honest caveat. We did not run any larger-model experiment. There is no measured number on this slide. Everything here is reasoning plus what other people have reported. Treat every claim as literature or proposed next step, never as something we measured.

First, the naming

There is no official "DistilBERT-large". DistilBERT only ships as a base model (~66M params, 6 layers). DistilBERT is itself a compressed version of BERT-base. So the real way to add capacity is to undo the compression and use a full-size encoder instead:

Why a bigger model should help — bias-variance reasoning

A model's expected error can be split into three parts. This is standard theory, not a measurement.

Expected error = bias² + variance + irreducible noise

bias² → how far the model class is from the true function (too simple = high bias)
variance → how much the fit changes with a different training sample
noise → label / data randomness we cannot remove

A larger encoder has more capacity, so it can fit the true function more closely. That lowers bias. This is the reason fine-tuned transformers were the best single models in the Jigsaw competition literature.

What we gain

  • Lower bias — more capacity to fit the true function.
  • Best single-model behaviour, matching the Jigsaw result literature.

What we pay

  • Higher variance / overfitting risk on a small balanced set (ours was 100,000 rows).
  • Much more compute and memory (BERT-large is ~340M vs ~66.96M).
  • Diminishing returns — each size step buys less.

We have a real reason to worry about the variance side. Our 3-epoch DistilBERT run already showed mild overfitting: training loss fell (0.6075 → 0.4207) while validation loss rose (0.537 → 0.818) with no accuracy gain measured by us. A larger model on the same small set would likely overfit sooner, not later.

Honest punchline. A single bigger model raises the ceiling, but it does not remove single-model variance or correlated errors — one model still makes the same kind of mistakes every time. In the Jigsaw competition no top team relied on one model; the best teams averaged several diverse models literature. That is what Stage 4 looks at.
Takeaway. Going bigger (BERT-base 110M or BERT-large ~340M) is the honest way to add capacity, and it would lower bias — but it costs far more compute and does not fix the variance problem. So the more useful next step is not "one bigger model", it is "several diverse models averaged together".
